# Soundboard & Ambience (Owlbear Rodeo)

## ติดตั้ง
1. อัปโหลดโฟลเดอร์นี้ทั้งหมด (ไม่ต้อง build เพิ่ม — มี `dist/` ให้แล้ว) ขึ้น static hosting เช่น GitHub Pages / Netlify / Cloudflare Pages
2. ใน Owlbear Rodeo: Profile → Add Extension → ใส่ `https://<โฮสต์ของคุณ>/manifest.json`
3. ทุกคนในห้องต้องเพิ่ม extension เดียวกัน (หรือ GM แชร์ลิงก์ให้)

## ใช้งาน
- **GM**: เปิดไอคอนลำโพง → วางลิงก์ YouTube / ลิงก์ไฟล์เสียง หรือนำเข้าไฟล์ → ▶ ⏹ 🔁 เลื่อนเวลา และปรับเสียงรวมของแต่ละเพลง
- **ผู้เล่น**: ปรับ "เสียงรวม" และ "เสียงของฉัน" ต่อเพลง / ปิดเสียงรายเพลงได้ (มีผลเฉพาะเครื่องตัวเอง)
- **Sync**: เก็บ "เวลาเริ่ม" ไว้ใน room metadata ผู้เล่นที่เข้ามาทีหลังจะคำนวณตำแหน่งปัจจุบันแล้วกระโดดไปตรงกันเอง + ตรวจ drift ทุก ~3 วิ
- **เสียงตามระยะ**: GM เลือก token/ของ → คลิกขวา → "ผูกเสียงกับของชิ้นนี้" → เลือกเสียงและรัศมี (ช่องกริด). ผู้เล่นฟังจาก token ตัวละคร (layer Character) ที่ตัวเองสร้าง; GM ฟังจาก token ที่เลือกอยู่ (ไม่เลือก = ดังเต็ม)

## ข้อจำกัด (ควรรู้)
- **ไฟล์ที่นำเข้าอยู่ในเครื่องที่นำเข้าเท่านั้น** Owlbear ไม่มีที่เก็บไฟล์เสียงให้ extension. ถ้าต้องการให้ทุกคนได้ยิน ให้ใช้ *ลิงก์* (ต้องเป็นไฟล์ตรง และเซิร์ฟเวอร์เปิด CORS เช่น GitHub raw, Cloudflare R2/Pages, Dropbox `?dl=1` อาจไม่ผ่าน CORS) หรือให้ผู้เล่นนำเข้าไฟล์ชื่อ/ขนาดเดียวกันเอง (ระบบจะขึ้นปุ่มให้)
- **YouTube ปรับความดังตามระยะได้ แต่แยกซ้าย-ขวาไม่ได้** (เบราว์เซอร์ไม่ให้เข้าถึงสัญญาณเสียงของ iframe YouTube). ไฟล์/ลิงก์เสียงตรงแยกซ้าย-ขวาได้ (ถ้าเซิร์ฟเวอร์ผ่าน CORS ไม่งั้นจะเล่นได้แต่ไม่แยกข้าง)
- รายการเสียงเก็บใน room metadata จำกัด ~16KB (ประมาณ 60–80 รายการ)
- เบราว์เซอร์ต้องการให้ผู้ใช้คลิกอย่างน้อยครั้งหนึ่งก่อนเล่นเสียง — ถ้าขึ้นแถบ "กดเพื่อเปิดเสียง" ให้กดหนึ่งครั้ง
- นาฬิกาเครื่องผู้เล่นควรตรงเวลา (ปกติอัตโนมัติ) ไม่งั้นจะเหลื่อมเป็นวินาที
- เสียงตามระยะ 1 เพลงต่อหลาย emitter ได้ — ใช้ emitter ที่ดังที่สุด; เพลงที่ผูกกับของแล้วจะเป็นเสียงอิงระยะเท่านั้น (ไม่เล่นดังทั่วแผนที่)

## พัฒนาต่อ
`npm i && npm run build` (โค้ดต้นฉบับอยู่ใน `src/`)
